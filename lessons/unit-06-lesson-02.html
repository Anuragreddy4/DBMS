UNIT 06 · LESSON 02

Index types & multilevel access

IN PLAIN WORDS

An index is a smaller guide that points toward data pages. Its layout trades extra space and update work for faster searches.

By the end, you can:
  • Distinguish dense and sparse indexes
  • Explain clustered and secondary indexes
  • Describe multilevel indexes and ISAM
TOPICS IN THIS LESSON

EXPLANATION
TOPIC 01

What an index does and when it helps

DEFINITION

An index is an auxiliary structure that maps search-key values to record or page locations so a query can find selected rows without scanning every data page.

An index can speed selective equality and range queries, but it uses storage and must be updated when rows change.

A table scan can be faster when most rows are needed. The DBMS chooses between an index path and a scan based on the query and estimated cost.

QUICK EXAMPLE

If a query requests one student id from a very large table, an index can jump near that row. If it requests every student, reading the table in order may cost less than visiting every index entry.

TOPIC 02

Dense and sparse indexes

DEFINITION

A dense index has an entry for every search-key value or record. A sparse index has fewer entries and searches within an ordered data page after locating the nearest index entry.

A sparse index needs the data file to be ordered on the search key. It often uses less space than a dense index.

An index entry stores a key and a pointer to a record or page.

QUICK EXAMPLE

If a sparse index stores the first key of each page, searching for key 37 starts at the page whose first key is the greatest value not above 37.

TOPIC 03

Primary, clustered, and secondary indexes

DEFINITION

A primary index is on the ordering key of an ordered data file. A clustered index follows the physical order of a non-key field. A secondary index is on a field the data file is not ordered by.

Clustered access can retrieve nearby matching records with fewer page reads. A secondary/unclustered index may point to scattered pages.

Indexes use storage and must be maintained when records change, so they are not free.

QUICK EXAMPLE

An enrollment file ordered by course id is clustered for course lookups; an index on student id may be secondary.

TOPIC 04

Multilevel indexes and ISAM

DEFINITION

A multilevel index places a small index over a larger index so each search narrows the page range.

ISAM is a static indexed sequential structure. The index levels stay fixed after creation, while new records may go to overflow pages.

Too many overflow pages slow searches; reorganizing can restore the main sequential layout.

QUICK EXAMPLE

Search the top index, follow one pointer to a lower index, then reach the data page.

WORKED EXAMPLE · SELECT A STEP

Find an ID with a small index

A book's contents page points to the first ID on each data page. We want to find student ID 37.

STEP 01

Find the nearest smaller starting ID

25 is the largest page-start ID that is not greater than 37.

STEP 02

Open that page

The index says IDs starting at 25 are on page 2, so check that page.

STEP 03

Look through the short range

Scan page 2 for 37. If the next ID is already larger, then 37 is not in the file.

RESULT

The index skips pages that cannot contain ID 37 and sends us straight to page 2. This is how a sparse index narrows a search.
