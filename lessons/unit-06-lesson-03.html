UNIT 06 · LESSON 03

B+ trees: search, insert & range scan

IN PLAIN WORDS

A B+ tree is a balanced index whose pages guide a search to a leaf. Its linked leaves make ordered and range searches efficient.

By the end, you can:
  • Read a B+ tree node and separator
  • Trace a search and leaf split
  • Explain root growth, height, and range scans
TOPICS IN THIS LESSON
01B+ tree structure↘02Search and insertion↘03Range queries and B-tree comparison↘
EXPLANATION
TOPIC 01

B+ tree structure

DEFINITION

A B+ tree is a balanced, page-based search tree. Internal pages hold separator keys and child pointers; leaf pages hold data entries and are linked in key order.

All root-to-leaf paths have the same length. A high fanout lets each page point to many children, keeping the tree shallow.

In a common order-m convention, an internal node has at most m children and a non-root node has at least ceil(m/2); some texts define order by maximum keys instead, so state the convention.

QUICK EXAMPLE

A search compares the target with separator keys at each internal page, follows one pointer, and checks the leaf.

TOPIC 02

Search and insertion

DEFINITION

Search follows separator ranges to a leaf. Insertion places a key in that leaf and splits a full page.

A leaf split keeps keys in order and copies a separator into the parent. If the parent is full, its split can continue upward.

If the root splits, a new root is created. The tree stays balanced because every leaf remains at the same depth.

QUICK EXAMPLE

Insert 12, 18, and 25 into a full leaf. Divide the entries between two leaves and insert a separator for the right leaf in the parent.

TOPIC 03

Range queries and B-tree comparison

DEFINITION

After finding the first matching leaf, a range query follows leaf links through the sorted entries.

This makes B+ trees useful for equality searches and ranges. Bulk loading sorts entries into leaves first and then builds parent levels.

A B-tree may store data entries in internal nodes as well as leaves. A B+ tree keeps all data entries at leaves, which increases internal fanout and supports leaf scans.

QUICK EXAMPLE

To list all students with sid from 100 to 160, find 100 once, then follow leaf links until the key exceeds 160.

WORKED EXAMPLE · SELECT A STEP

Split a full B+ tree leaf

For this tiny example, one leaf box can hold at most two numbers. It currently holds 12 and 18. Insert 25.

STEP 01

Put the new number in order

The leaf becomes [12, 18, 25], but the example leaf has room for only two numbers.

STEP 02

Make a second leaf

Keep [12, 18] in the first leaf and put [25] in a new leaf to its right.

STEP 03

Update the parent

Put 25 in the parent as a signpost. A search for 25 or more follows the pointer to the new leaf.

RESULT

A B+ tree splits a full leaf and updates its signpost. The leaves stay in sorted order, so searches can continue correctly.

EXAM FOCUS

What to be ready to explain

Draw a B+ tree and trace search, insert, split, root growth, and range scan. State the order convention and compare B+ trees with B-trees.
